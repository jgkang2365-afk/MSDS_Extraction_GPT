# MSDS Golden Dataset

이 디렉터리는 MSDS 추출 엔진의 회귀 검증용 사람 확인 정답을 보관합니다.

## 현재 범위

- `msds_golden_v1.json`: 회귀 이력이 있거나 레이아웃이 특이한 13개 PDF
- `TEST_File`에서 파일명에 `★`가 붙은 PDF는 모두 필수 사례로 포함
- 제품명: 1섹션에 기재된 제품명 원문 기준
- 구성성분: 3섹션에 명시된 유효 CAS 번호와 해당 함유량만 대상
- CAS가 없는 성분: `cas_missing_components`에 별도 기록하며 추출 기대값에는 포함하지 않음
- 3섹션 밖 CAS: 누락/과다 판정에서 제외
- 원본 PDF 동일성: 각 사례의 `source_sha256`로 확인

## 함유량 정규화 원칙

- `-`, `~`, `～` 범위 표시는 `~`로 통일
- 범위의 좌우 부등호는 제거하되 상한이 정확히 `1`이고 원문이 미만이면 `<1`을 보존
- 단일 `<`, `>`, `≤`, `≥`는 보존
- 원문이 역순 범위이면 오름차순으로 정렬
- 원문 자체가 100%를 초과하더라도 임의 보정하지 않고 정답에 보존하고 메모로 표시

## 회귀 판정 원칙

1. 제품명은 `product_name.expected` 또는 `allowed_variants` 중 하나와 일치해야 합니다.
2. `components`의 CAS 집합은 순서와 함께 정확히 일치해야 합니다.
3. 각 CAS의 `content_expected`가 정확히 일치해야 합니다.
4. `cas_missing_components`에 있는 항목으로 CAS를 환각 생성하면 실패입니다.
5. 3섹션 밖 CAS가 결과에 포함되면 실패입니다.
6. `TEST_File`의 `★` PDF가 골든 데이터에서 하나라도 누락되면 데이터셋 검증 실패입니다.

`review_status`가 `draft`인 동안은 사람이 원문과 한 번 더 대조한 뒤 `approved`로 전환합니다.
