## 승인 결정 변환

`동일CAS_우선검토` 27건과 `교차CAS_16건` 16건, 총 43건을 읽었다. 승인 Excel의 사용자 입력을 최우선으로 적용하고 원본 셀 값과 행 번호를 lineage로 보존했다.

- 금홍석은 이산화티타늄과 기타광물성분진을 각각 기본 선택 가능한 복수 추천으로 생성했다.
- 크리스토발라이트와 트리디마이트는 석영을 직접 검출이 아닌 분석 관계 추천으로 생성했다.
- 무정형 실리카의 석영 추천은 기본 선택하지 않는다.
- 활석 CAS의 직접 선택지는 `활석(석면불포함)`과 `소우프스톤(호흡성)`으로 분리했다. 부모·대표 profile은 검색·그룹 기준으로 활성 보존하되 선택지로 중복 표시하지 않는다.
- 석면 포함 여부가 불명확한 활석의 석면 추천은 사용자 확인이 필수이며 활석을 자동 대체하지 않는다.
- XCAS-014는 비활성 `REVIEW_REQUIRED`로 보존했다. XCAS-004는 실행 추천 규칙에서 제외했다.
- 복수선택 값이 공란인 XCAS-007과 XCAS-008은 추정하지 않고 비활성 `REVIEW_REQUIRED`로 보존했다.

## loader, resolver와 호환 처리

`DatasetIndex`는 CAS·이름·별칭·구 정렬코드로 profile을 찾는다. `SubstanceResolver`는 직접 검출, 동일 CAS 변형, 공정 추천, 분석 관계 및 저장 선택 복원을 서로 다른 `selection_source`로 반환한다. 저장용 선택은 `profile_id`와 출처를 함께 직렬화한다.

기존 `selected_code_{cas}` 값은 정렬코드가 유일하게 대응할 때 `profile_id`로 이관할 수 있다. 대응하지 않는 값은 자동 추정하지 않고 기존 경로에 남겨 사용자 확인 대상으로 삼는다.

GUI 파일은 수정하지 않았다. `MSDS_DATASET_V2` 환경 플래그 판정 함수만 adapter에 제공하며 기본값은 꺼짐이다. 따라서 현재 GUI와 MSDS 추출 엔진의 운영 경로는 그대로 유지된다.

## 검증 결과와 잔여 검토

builder 실행 시 validator ERROR는 0건이다. WARNING은 사용자 결정의 충돌 가능성과 승인 데이터의 구조를 보존하기 위한 것으로, 기본 선택이면서 복수선택 N인 3개 규칙, 동일 CAS에 부모·대표가 둘인 5개 그룹, 선택 불가 부모에 기본추천이 설정된 1개 항목이다.

사람 검토가 남은 항목은 XCAS-007, XCAS-008의 복수선택 정책과 XCAS-014의 황화니켈·황산니켈 분리 규칙이다. GUI 실제 전환 전에는 후보 표시, 초기 체크, 복수선택 제한, 사용자 확인 대화상자 및 기존 저장값 migration을 통합 회귀시험해야 한다.

## 회귀 위험

- 동일 CAS 최초행만 쓰던 화면은 후보 수와 표시명이 달라질 수 있다.
- 원인자를 추천인자로 치환하던 기존 규칙을 추가 추천으로 바꾸면 결과 행 수가 늘 수 있다.
- `default_selected=true`, `allow_multiple=false`인 승인 규칙은 화면 선택 정책을 명확히 구현해야 한다.
- 구 정렬코드 저장값 중 중복·삭제 코드는 자동 이관할 수 없다.
- 현 단계에서는 feature flag 기본값이 꺼져 있어 이 위험이 운영 GUI에 적용되지 않는다.
