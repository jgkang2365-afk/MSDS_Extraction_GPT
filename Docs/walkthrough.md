# Walkthrough: MSDS Zero-Touch v4.0 추출 파이프라인

시니어 아키텍트의 설계 가이드를 바탕으로 구현된 **MSDS Zero-Touch v4.0**의 주요 기능과 작동 원리를 설명합니다.

## 1. 주요 변경 사항 및 성과

### 🎯 Zero-Touch 자동화 완성
- **인간 개입 최소화**: 추출된 데이터의 무결성을 AI가 스스로 판단하여 `[PASS]`(즉시 사용 가능) 또는 `[REVIEW]`(검토 필요) 태그를 부여합니다.
- **수치 폭주 완벽 차단**: 100%를 초과하거나 좌표값이 유입된 비정상적인 함유량 수치를 `Value Guard`가 실시간으로 필터링합니다.

### 🧠 공간 문맥 기반 LLM 추론 (Visual Context)
- 단순히 텍스트를 나열하는 대신, PDF의 공간 좌표를 활용하여 **가시적인 문맥(Visual Context)**을 재구성해 LLM(Ollama)에 전달합니다. 이를 통해 표 구조가 복잡한 문서에서도 정확한 성분 관계를 파악합니다.

## 2. 핵심 컴포넌트 작동 방식

### [Visual Context Builder]
앵커(제품명/구성성분)를 중심으로 주변 300~1000px의 텍스트를 수집하고, 멀티 공백과 줄바꿈(`\n`)을 사용해 문서의 시각적 형태를 모사합니다.

### [Confidence Engine]
LLM이 추출한 결과를 다음 3단계로 검증합니다:
1. **CAS Checksum**: CAS 번호의 유효성 검사.
2. **Content Guard**: 함유량 합계가 100%를 초과하거나 비정상적인 수치인지 확인.
3. **Consistency Check**: 제품명 내 금지어나 섹션 제목 오인식 여부 확인.

## 3. 결과 화면 예시 (로그)

```text
신뢰도 판정   |  [PASS]   | 검토 불필요: 모든 검증 통과
🧐 [LLM 추론근거] 제품 식별자 섹션에서 'Shikimic acid'를 제품명으로 특정하였으며, 표 구조에서 성분 3종의 CAS와 함유량이 명확히 일치함.
```

## 4. 향후 계획
- **지속적 학습**: `[REVIEW]` 태그가 붙은 특수 레이아웃 사례를 모아 `patterns.json` 및 프롬프트를 지속적으로 튜닝할 예정입니다.
