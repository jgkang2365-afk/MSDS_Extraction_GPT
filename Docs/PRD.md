# PRD: MSDS Zero-Touch 추출 파이프라인 (v3_하이브리드)

## 1. 배경 및 목적
기존의 정적인 정규식 기반 추출은 PDF의 다양한 레이아웃 변화에 대응하지 못해 'Unknown' 및 비정상 수치(예: 17036%)를 생성하는 한계가 있었습니다. 본 프로젝트는 공간 지능(Spatial Intelligence)과 시맨틱 추론(LLM)을 결합하여 인간의 검토가 필요 없는 수준의 완전 자동화(Zero-Touch)를 목표로 합니다.

## 2. 핵심 요구사항
- **[REQ-01] 가시적 문맥 수집**: 앵커 주변 300px 내의 모든 텍스트를 좌표 순서(상->하, 좌->우)대로 수집하여 표 구조를 보존합니다.
- **[REQ-02] 이중 검증 레이어**: LLM이 제안한 값은 반드시 `msds_utils_v3.py`의 물리적 검증 로직(체크디지트, 100% 리미트)을 통과해야 합니다.
- **[REQ-03] 신뢰도 자동 라벨링**: 모든 검증 통과 시 [PASS], 하나라도 오류 발생 시 [REVIEW] 태그를 생성합니다.
- **[REQ-04] GUI 정보 고도화**: 단순 텍스트 로그가 아닌, **[추출 근거 / 신뢰도 점수 / 오류 유형]**을 표 형식으로 출력하여 사용자의 분석 편의성을 극대화합니다.
- **[REQ-05] 런타임 핫-리로드**: GUI의 '새로고침' 클릭 시, 프로그램 재시작 없이 수정된 `msds_engine_v3.py`와 `patterns.json`이 즉시 반영되어야 합니다.
