# MSDS v3_하이브리드: Zero-Touch

## 📖 개요
이 시스템은 단순한 텍스트 추출기가 아닙니다. 공간 정보를 읽고 LLM의 지능을 통해 정답을 도출한 후, Python 로직으로 최종 검증하는 '자율 주행형' 데이터 파이프라인입니다.

## 🛠️ 사용 방법
1.  **[PASS] 확인**: 태그가 [PASS]인 파일은 신뢰도가 99%이므로 별도 검토가 필요 없습니다.
2.  **[REVIEW] 처리**: 로그창의 '추출 근거'를 확인하여 시스템이 모호하다고 판단한 부분만 수동 수정합니다.
3.  **규칙 수정**: `patterns.json` 수정 후 GUI에서 '새로고침'을 누르면 즉시 반영됩니다.
