# Release Checklist

## 코드와 저장소

- [ ] 작업 브랜치가 main과 분리되어 있다.
- [ ] 작업 트리에 의도하지 않은 변경이 없다.
- [ ] .env, vertex_key.json, .venv, 로그가 추적되지 않는다.
- [ ] 의존성 잠금 파일이 실제 환경과 일치한다.

## 정적 검증

- [ ] Python 문법 검사가 통과한다.
- [ ] pip check가 통과한다.
- [ ] 단위 테스트가 전부 통과한다.
- [ ] 오프라인 엔진 회귀 14/14가 통과한다.

## 골든 검증

- [ ] 골든 JSON 구조와 PDF SHA-256 검증이 통과한다.
- [ ] 필수 별표 PDF가 모두 포함되어 있다.
- [ ] 실제 엔진 회귀 13/13이 통과한다.
- [ ] 제품명 허용 정답이 모두 일치한다.
- [ ] CAS 순서와 집합이 모두 일치한다.
- [ ] 함유량이 모두 일치한다.
- [ ] 3섹션 밖 CAS 오탐이 없다.
- [ ] CAS 없는 성분의 CAS 환각이 없다.
- [ ] False Green이 없다.

## 실행 환경

- [ ] Python 3.12 깨끗한 환경에서 설치된다.
- [ ] PaddlePaddle 호환 버전으로 스캔본이 실행된다.
- [ ] 디지털 대표 문서가 실행된다.
- [ ] 순수 스캔 대표 문서 005와 046이 실행된다.
- [ ] 외부 AI 인증 실패 시 안전하게 격리된다.

## GUI와 운영

- [ ] GUI가 시작된다.
- [ ] PDF 추가와 1단계 추출이 동작한다.
- [ ] 결과 수정과 2단계 검증이 동작한다.
- [ ] 저장·내보내기 핵심 흐름이 동작한다.
- [ ] 오류 한 건이 전체 배치를 중단시키지 않는다.
- [ ] 캐시 초기화와 재실행이 가능하다.

## 문서와 승인

- [ ] README의 현재 상태가 정확하다.
- [ ] CURRENT_SPEC에 확정 정책이 반영되어 있다.
- [ ] DECISION_LOG에 주요 결정이 기록되어 있다.
- [ ] 회귀 보고서가 최신 결과를 담고 있다.
- [ ] 사용자에게 알려진 제한 사항이 정리되어 있다.
- [ ] main 병합과 릴리스 승인을 받았다.

## 릴리스

- [ ] 최종 커밋 해시를 기록했다.
- [ ] Private GitHub 원격에 push했다.
- [ ] 버전 태그를 만들었다.
- [ ] 롤백 대상 이전 태그를 확인했다.
