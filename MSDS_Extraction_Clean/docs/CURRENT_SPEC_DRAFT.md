# Current Specification Draft

이 문서는 기존 역사 문서와 현행 규칙을 분리하기 위한 초안입니다. 사용자 확정 전에는 미결 정책을 코드에 적용하지 않습니다.

## 확정된 범위

- 1섹션에서 제품명을 추출한다.
- 3섹션에서 유효 CAS 번호와 해당 함유량을 추출한다.
- CAS 번호가 없는 성분은 최종 CAS 결과에서 제외하되 골든 데이터의 `cas_missing_components`에 기록한다.
- 3섹션 밖 CAS는 구성성분 누락·과다 판정에서 제외한다.
- 승인된 `golden/msds_golden_v1.json`을 회귀 정답의 기준으로 사용한다.
- 파일명에 `★`가 붙은 PDF는 필수 회귀 대상으로 유지한다.
- 한 파일을 수정한 뒤 전체 골든 세트가 통과하지 않으면 변경을 완료로 간주하지 않는다.
- 사용자가 수정 내용을 이해하고 승인하기 전에는 엔진 코드를 변경하지 않는다.

## 강제 구현 제한

- 디지털 PDF와 이미지/OCR PDF 모두에서 문서 전체 페이지를 읽거나 외부 AI에 전송하는 구현을 금지한다.
- 제품명은 1섹션으로 확정된 제한 범위에서만 추출한다.
- 구성성분은 3섹션으로 확정된 페이지·영역에서만 처리하고 4섹션 시작 경계에서 중단한다.
- 전체 문서 판독을 fallback으로 사용하지 않는다. 제한 범위에서 섹션을 확정하지 못하면 실패 또는 사용자 검토 상태로 반환한다.
- 3섹션의 추출 대상은 CAS 번호와 원문 함유량뿐이다. 구성성분명은 추출·정제·복구·저장하지 않는다.
- 공식 구성성분명은 후단 공단 API에서 CAS 번호를 기준으로 매핑한다.
- CAS가 없는 구성성분의 이름을 근거로 CAS 번호를 추정하거나 생성하지 않는다.

## 확정된 AI 운영 원칙

- 제품명(1섹션)과 구성성분(3섹션)은 서로 다른 목적형 호출로 유지한다. 비용 절감을 이유로 두 임무를 기본 통합 원샷 호출로 합치지 않는다.
- 외부 AI 결과는 로컬 완전성 게이트에서 다시 검증한다. 로컬 결과와 AI 결과가 충돌하면 자동 확정하지 않고 노란불로 표시하여 사용자 검토 대상으로 보낸다.
- 공급자, 실제 모델 ID, 입력·출력 토큰, 호출 시간, 재시도 횟수, 성공 여부, 추정 비용을 호출 단위로 계측한다. 비밀키와 원문 민감정보는 계측 로그에 저장하지 않는다.
- `gemini-2.5-flash-lite`는 Vertex AI 안정판을 대상으로 재평가한다. 즉시 전면 교체하지 않고 저위험 작업에서 품질과 비용을 검증한 뒤 적용 범위를 결정한다.
- Flash-Lite 우선 검토 대상은 제품명 추출과 간단한 디지털 텍스트 정제이다.
- 복잡한 3섹션 표, 다중 페이지, 세로 카드, 저화질 순수 스캔 문서는 검증 전까지 Gemini 2.5 Flash를 유지한다.
- Flash-Lite 결과가 로컬 완전성 게이트를 통과하지 못하면 Gemini 2.5 Flash로 승격한다. 429 오류에는 제한된 지수 백오프와 지터 재시도를 먼저 적용하고, 재시도 한도를 넘긴 뒤에만 모델 fallback을 수행한다.

## 미결 정책

- 함량 합계 허용 상한: 110% 또는 130%
- 원문이 100%를 초과하는 경우의 일반 정책과 Glycine 예외
- False Green 감지 시 로그만 기록할지 신호등을 낮출지 여부
- 제품명 파일명 보정 사용 여부
- 완전한 1선 결과에서 제품명 AI 호출까지 생략할지 여부
- Flash-Lite의 정식 기본 경로 채택 여부와 작업 유형별 승격 임계값
