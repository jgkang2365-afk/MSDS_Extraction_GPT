# MSDS Extraction Cleanroom 구현 강제 규칙

이 파일의 규칙은 이 저장소에서 수행하는 설계, 코딩, 테스트, 리팩터링에 항상 적용한다. 하위 계획이나 과거 역사 문서가 충돌하면 이 규칙을 우선한다.

## 1. PDF 전체 페이지 판독 금지

- 디지털 PDF와 이미지/OCR PDF 모두에서 문서 전체 페이지를 읽거나 외부 AI에 보내는 구현을 금지한다.
- 1섹션 제품명은 1섹션으로 확인된 제한 범위만 읽는다.
- 3섹션 구성성분은 3섹션으로 확인된 페이지·영역만 읽고, 4섹션 시작 경계에서 반드시 중단한다.
- OCR과 비전 호출도 필요한 페이지와 크롭 영역에만 적용한다.
- 다른 섹션의 이미지·텍스트가 추출 입력에 섞이지 않도록 섹션 경계를 먼저 확정한다.
- 전체 페이지 순회나 전체 문서 비전 전송을 fallback으로 추가하지 않는다. 제한 범위에서 섹션을 확정하지 못하면 자동 확대 판독하지 말고 실패 또는 사용자 검토 상태로 반환한다.

이유: 타 섹션 이미지·텍스트의 오인입 가능성을 차단하고 OCR·AI 처리시간과 API 비용을 줄이기 위함이다.

## 2. 3섹션 구성성분명 추출 금지

- 3섹션에서 추출할 필드는 CAS 번호와 원문 함유량뿐이다.
- 구성성분의 한글명, 영문명, 관용명, 화학물질명은 추출·정제·복구·저장하지 않는다.
- AI 프롬프트와 결과 스키마에도 3섹션 구성성분명 필드를 요구하거나 추가하지 않는다.
- 공식 구성성분명은 후단 공단 API가 추출된 CAS 번호를 기준으로 매핑한다.
- CAS가 없는 구성성분에 이름을 근거로 CAS 번호를 추정하거나 생성하지 않는다.

이유: 구성성분명 처리에 쓰이는 토큰과 연산을 제거하고 CAS 번호·함유량의 정확도에 자원을 집중하기 위함이다.
