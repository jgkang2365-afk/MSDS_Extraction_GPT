# [GSD2] GUI 파일 선택 영속성(Persistence) 구현 계획

## 1. 개요
GUI를 종료하고 다시 열었을 때, 이전에 선택했던 PDF 파일 목록과 엑셀 설정이 그대로 유지되도록 합니다. 현재 `smu_gui.py`에 존재하는 중복 메서드와 `pdf_paths` 저장 누락 문제를 해결합니다.

## 2. 작업 상세 (FTF 프로토콜 적용)

### [Forest] 사전 분석
- **중복 메서드 문제**: `closeEvent`와 `save_config`가 파일 내에 여러 번 정의되어 있어, 마지막에 정의된 '불완전한' 버전이 실행되고 있음.
- **캐시 로드 누락**: `self.cache`를 파일에서 읽어오는 `load_cache()`가 `__init__`에서 호출되지 않고 있음.
- **테이블 복구 로직 부재**: `pdf_paths`를 불러오더라도 화면상의 테이블(`self.table`)에 즉시 표시하는 로직이 없음.

### [Tree] 정밀 수정 단계

#### 🛠️ 제1작업: 초기화 및 세션 복구 로직 강화
- `__init__`: `self.load_cache()` 호출 추가.
- `load_config`: `pdf_paths`를 불러온 후, `self.restore_table_from_session()` (가칭)을 호출하여 테이블을 채움.

#### 🛠️ 제2작업: 중복 코드 정리 및 통합
- 파일 하단(L2298-2313)의 중복된 `closeEvent` 및 `save_config` 삭제.
- 파일 중간(L1325-1331)의 `closeEvent` 삭제.
- L1951의 `closeEvent`를 최종 통합 버전으로 유지 (안전장치 + `save_config` 호출).
- `save_config`는 `pdf_paths`를 포함하는 버전(L1332)으로 단일화.

#### 🛠️ 제3작업: 세션 복구 함수 구현
- `restore_table_from_session()`:
  - `self.pdf_paths` 순회.
  - 각 파일의 해시 계산 후 캐시 데이터가 있으면 `add_result_to_table` 호출.
  - 캐시가 없더라도 파일명 정보 등을 테이블에 기본 행으로 추가하여 "선택된 상태"를 시각화.

### [Forest] 사후 검증
- 프로그램 재시작 시 파일 목록이 테이블에 나타나는지 확인.
- 엑셀 경로 및 시트 선택 상태가 유지되는지 확인.
- 중복 메서드 제거 후 다른 기능(추출, 저장 등)에 영향이 없는지 확인.

## 3. 성공 기준 (UAT)
1. PDF 파일을 추가하고 프로그램을 껐다 켰을 때, 해당 파일들이 테이블 목록에 그대로 존재함.
2. 분석이 완료된 파일은 분석 결과(성분 등)까지 함께 복구됨.
3. 엑셀 설정(경로, 시트명 등)이 정상적으로 로드됨.
