# [GSD2] V15.8.8: 누락 탐지기 고도화 (Count-based Omission Detection)

## 1. 개요
현재 `check_omission`은 `set()`을 사용하여 중복된 CAS 번호를 하나로 취급합니다. 하지만 실제 MSDS에서는 동일한 성분이 다른 농도로 여러 번 나타날 수 있습니다. 이를 정확히 포착하기 위해 '집합'이 아닌 '카운트' 기반의 검증으로 고도화합니다.

## 2. 작업 상세 (FTF 프로토콜 적용)

### [Forest] 사전 분석
- **현상**: 동일 CAS 번호가 여러 행에 존재할 경우, 원본 카운트는 1로 잡히지만 추출 데이터는 N개가 되어 검증 정밀도가 떨어짐.
- **영향**: 반대로 원본에 2번 나오는데 1번만 추출한 경우, `set()` 기반에서는 누락으로 잡히지 않음.

### [Tree] 정밀 수정 단계

#### 🛠️ [누락 탐지기 수술] `msds_engine_v5.py`
- `check_omission` 내부에서 `set()` 제거.
- 단순 `len()` 비교가 아닌, 개별 CAS 번호의 출현 횟수를 비교하거나 전체 개수 합산 비교로 전환.
- **V15.8.8 원칙**: 추출된 총 성분 개수가 원본에서 발견된 유효 CAS 번호의 총 개수보다 적으면 무조건 누락으로 간주.

### [Forest] 사후 검증
- [ ] 중복 CAS가 포함된 테스트 텍스트로 누락 감지 테스트.
- [ ] `py_compile` 검사.
