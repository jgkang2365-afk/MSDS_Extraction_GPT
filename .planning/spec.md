# [안티(Anti) GSD2] msds_engine_v5.py & smu_gui.py 통합 패치 계획서

## 1. 개요
`msds_engine_v5.py`의 V12.6 패치에 이어, `smu_gui.py`의 과잉 필터 제거 및 인식 강화 패치를 수행합니다.

## 2. 세부 작업 항목

### [작업 1-3] msds_engine_v5.py 패치 (완료)
- V24 코어 찌꺼기 제거
- 데이터 보존 로직 개선
- AI 프롬프트 V12.6 업데이트

### [작업 3.1] msds_engine_v5.py: CAS 무결성 확립 및 '영업비밀' 필터링
- **CAS 무결성**: `process_pdf` 내에서 CAS 번호 규격(`^\d{1,7}-\d{2}-\d$`)이 아닌 데이터(영업비밀 등)는 모두 제거(continue)합니다.
- **함유량 보존**: CAS 번호는 정상이나 함유량이 비어있거나 '없음' 등인 경우 '미기재%'로 보존합니다.
- **찌꺼기 제거**: 기존에 추가했던 '영업비밀' 강제 치환 로직을 제거합니다.

### [작업 4] smu_gui.py: 2단계 검증 시 영업비밀 보존 로직 추가 (완료)
- 비-CAS 데이터 보존 및 복구 로직 적용 완료.

### [작업 5] smu_gui.py: 1% 과잉 필터 제거 및 용접 인식 강화
- **데이터 필터 제거**: `update_validation_row` 내의 `is_above_one_percent` 과잉 필터 로직을 삭제하고 원본 리스트를 그대로 사용합니다.
- **용접 인식 보강**: `ValidationWorker.run()` 내 `is_welding` 조건에 영문 'welding'을 추가합니다. (대소문자 구분 없음)
- **주의 사항**: `ValidationWorker.run()` 내의 1% 미만 '측정 비대상' 분류 로직은 유지합니다.

## 3. 검증 계획
- 코드 수정 후 구문 오류 확인 (FTF 프로토콜 준수)
- 2단계 검증 시 1% 미만 성분이 필터링되지 않고 유지되는지 확인
- 제품명에 "welding" 포함 시 용접 보정 로직이 정상 작동하는지 확인

## 4. 제약 사항
- `ValidationWorker.run()`의 `res_work_non_subjects.append` 관련 로직은 절대 수정 금지
- 1,000줄 이상의 파일 전체 재작성 금지 (부분 수정 수행)
