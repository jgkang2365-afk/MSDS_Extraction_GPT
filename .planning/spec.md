# 프롬프트 관리 체계화 및 아카이빙 계획 (v1.1)

## 1. 개요
엔진 버전 업데이트에 따라 누적되는 프롬프트 파일을 효율적으로 관리하기 위해 아카이브 구조를 도입한다. 모든 폴더는 프로젝트 루트(`MSDS_EXtaction_V3(v24+GUI통합)`) 하위에 위치한다.

## 2. 변경 사항
### 📂 폴더 구조 (프로젝트 루트 기준)
- `prompts/` : 현재 활성 버전 프롬프트 보관
- `prompts/archive/` : 구버전 프롬프트 격리 보관

### 🚚 파일 이동 작업
- **대상**: `17.3.2.27`, `17.3.2.28`, `17.3.2.29` 버전 프롬프트
- **이동지**: `prompts/archive/`
- **유지**: 엔진 버전(`17.3.2.30`)에 해당하는 파일은 `prompts/` 폴더에 유지 (없을 경우 29버전 기반 생성)

### 🛠️ 코드 수정 (`msds_engine_v5.py`)
- `load_prompt` 함수가 `./prompts/`뿐만 아니라 `./prompts/archive/` 경로도 순차적으로 탐색하도록 수정.

## 3. 검증 계획
- [ ] 프로젝트 루트 내 `prompts/archive` 생성 확인
- [ ] 구버전 파일 이동 완료 확인
- [ ] `msds_engine_v5.py` 로드 테스트 시 `archive` 폴더 내 파일 인식 여부 확인
