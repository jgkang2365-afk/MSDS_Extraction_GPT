# [GSD2] V15.8.8: PDF 페이지 트래킹 및 GUI 동기화 고도화

## 1. 개요
현재 `smu_gui.py`에서 테이블 행을 클릭하면 PDF 미리보기가 1페이지로 고정되는 한계를 극복합니다. 엔진이 추출한 `page` 정보를 활용하여 사용자가 클릭한 성분의 위치로 즉시 스크롤되는 '지능형 페이지 트래킹'을 구현하고, 엔진의 누락 탐지 로직을 보강합니다.

## 2. 작업 상세 (FTF 프로토콜 적용)

### [Forest] 사전 분석
- **현상**: `smu_gui.py`의 `on_row_clicked` 메서드에서 `verticalScrollBar().setValue(0)`으로 하드코딩되어 있음.
- **데이터 구조**: `msds_engine_v5.py`는 이미 `page` 정보를 반환하고 있으며, 테이블의 10번 컬럼(숨김)에 저장되고 있음.
- **누락 탐지**: `check_omission`에서 `set()`을 사용하여 중복 CAS가 있는 경우 탐지력이 약화될 가능성 검토.

### [Tree] 정밀 수정 단계

#### 🛠️ 미션 1: PDF 지능형 페이지 트래킹 구현 (`smu_gui.py`)
- `on_row_clicked`: 
    - 10번 컬럼(`COL_IDX_PAGE`)에서 페이지 번호를 읽어옴.
    - `self.preview_pane.navigate_to_page(page_num)` 호출.
    - 예외 처리: 페이지 번호가 없거나 잘못된 경우 1페이지로 기본 이동.

#### 🛠️ 미션 2: 누락 탐지기(Omission Detector) 정교화 (`msds_engine_v5.py`)
- `check_omission`:
    - 원본 텍스트의 CAS 출현 빈도와 추출된 빈도를 대조하도록 개선.
    - 로그 출력 시 어떤 CAS가 누락되었는지 구체적으로 명시하여 디버깅 편의성 증대.

#### 🛠️ 미션 3: GUI 세션 복구 안정성 검증
- `restore_table_from_session`이 모든 캐시 데이터를 무결하게 복구하는지 최종 확인.

### [Forest] 사후 검증
- [ ] 테이블 행 클릭 시 PDF 미리보기가 해당 페이지로 이동하는지 확인.
- [ ] 다중 페이지 MSDS에서 성분별 페이지 매칭 정확도 테스트.
- [ ] `py_compile` 및 런타임 오류 체크.

## 3. 성공 기준 (UAT)
1. 3페이지에 있는 성분 행을 클릭하면 PDF 미리보기가 3페이지로 자동 스크롤됨.
2. 성분 추출 시 페이지 번호가 정확히 테이블에 기록됨.
3. 누락 탐지기가 작동할 때 어떤 CAS 번호가 누락되었는지 로그에 표시됨.
