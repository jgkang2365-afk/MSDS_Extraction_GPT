# 🧬 MSDS Extraction Engine V17.4.0.0 Specification

## 1. 프로젝트 개요
MSDS 성분 함량 추출 엔진의 정밀도를 100%에 근접시키기 위해, 구조적 분석(ODL)과 문맥적 추론(AI)을 완전히 분리하고 정규화 로직을 강화함.

## 2. 엔진 이원화 원칙 (Bifurcation Strategy)
- **ODL (Structural)**: 표(Table) 형태가 명확한 데이터만 전담. 구조적 무결성 중시.
- **AI (Contextual)**: 스캔본, 줄글, 복잡한 문맥 전담. 원본 데이터를 있는 그대로 제공하여 AI의 추론 능력 극대화.

## 3. 핵심 모듈별 설계 사양

### 3.1. 정규화 로직 (_normalize_single_content)
- **Year Shield**: 연도(2024)나 날짜(2024.01.01)를 함량 수치로 오인하지 않도록 사전 마스킹.
- **Strict Range**: 숫자 사이에 `~`, `-`, `to` 등 명확한 구분자가 있을 때만 범위(Range)로 인정.
- **Capping**: 사용자 지침에 따라 110%를 초과하는 수치는 즉시 탈락.

### 3.2. AI 공급망 (AI Context Provision)
- **Unmasking**: 기존의 '데이터 다이어트'를 폐지하고, 섹션 2~4 범위의 원본 텍스트(Raw Text)를 제공.
- **Reference Mode**: 제품명 추출 시 텍스트 레이어는 '참고'로만 활용하고, 비전(Vision) 결과를 우선함.

### 3.3. 엔진 전환 로직 (Engine Handover)
- **Scanned First**: 텍스트 레이어가 없는 스캔본은 ODL을 건너뛰고 즉시 AI Sniper 투입.
- **Verification Loop**: ODL 결과가 텍스트 원본 대비 누락이 감지되면 즉시 AI Sniper 투입.
