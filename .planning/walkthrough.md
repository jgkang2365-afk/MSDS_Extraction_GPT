# [Walkthrough] MSDS Intelligence V15.6 아키텍처 대통합 완료

## 1. 개요
추출 엔진(`msds_engine_v5.py`)의 복잡한 후행 검증 로직을 단일 함수로 모듈화하여, 아키텍처의 투명성을 높이고 데이터 신뢰도를 강화했습니다.

## 2. 주요 변경 사항 (V15.6)

### 🏥 중앙 통제형 후행 교정 엔진 (`final_quality_control`)
- **환각 차단(Grounding)**: AI가 추출한 CAS 번호가 실제 PDF 텍스트 내에 존재하는지 물리적으로 팩트 체크하여 폐기합니다.
- **1% 부등호 강제 복원**: AI가 `1~5%` 등으로 뭉뚱그린 경우에도, 원본에 `1% 미만` 기호가 있다면 `<1%`로 정밀 복원합니다.
- **수학적 검증**: CAS 체크섬 알고리즘을 통해 오타 및 허위 번호를 원천 차단합니다.
- **표준화**: 부등호 기호(`<`, `≤` 등)를 표준 규격으로 통일합니다.

### 🧹 파이프라인 정제
- `process_pdf` 함수의 Phase 6 루프를 단 4줄의 코드로 단순화하여 가독성을 극대화했습니다.
- 불필요한 이중 정제 로직(`minimal_clean`)을 삭제하고 통합 엔진으로 단일화했습니다.

## 3. 검증 결과
- **구문 검증**: `py_compile` 통과 완료.
- **버전 확인**: 시스템 전역 버전 `15.6` 반영 완료.

## 6. 추가 변경 사항 (V24.4.3.9)
### 🎛️ 성상 선택 팝업 내 복수 선택 동적 활성화 및 단수/복수 제어 기능 추가
- **요구사항 구현**: 기본적으로 팝업 목록 내에서는 단수 선택만 가능하도록 제어하고, 사용자가 복수 선택이 필요할 때 직접 활성화하거나 크롬 성상 같은 특수한 상황에서만 복수 선택이 디폴트 활성화되도록 구현했습니다.
- **수정 내용**: `SubstanceSelectDialog` 팝업 레이아웃에 "복수 선택 활성화" 체크박스를 주입하고, 체크되지 않은 단수 선택 모드에서는 하나의 후보를 체크할 때 다른 체크박스가 시그널 일시 차단 하에 자동 해제(라디오 버튼화)되도록 이벤트를 연동했습니다. 기존 다중 저장 이력이 2개 이상 있을 경우 자동으로 활성화되게 하여 기존 매칭도 보호합니다.
- **검증**: 파이썬 구문 문법 검사(`py_compile`) 완료.

## 7. 추가 변경 사항 (V24.4.3.10)
### ⌨️ 측정대상(4번 열) 셀 직접 수동 타이핑 수정 제약 해제 및 최우선 보존
- **문제 진단**: `HTMLDelegate`에서 4번 열(측정대상)에 대해 텍스트 편집기 생성을 무조건 `None`으로 차단하고 있어, 일반 텍스트 상태의 셀임에도 더블클릭이나 F2 키를 눌렀을 때 직접 수정할 수 없었습니다.
- **수정 내용**: `HTMLDelegate`의 `createEditor` 메서드에서 4번 열의 에디터 생성을 조건부로 허용했습니다. 성상 선택 버튼(`QPushButton`)이 올라가 있거나 아직 1:N 팝업 선택이 완료되지 않은 경우에만 에디터를 차단하고, 일반 텍스트 상태의 셀일 때는 `QTextEdit`를 생성하여 자유롭게 타이핑할 수 있게 수정했습니다.
- **최우선 보존**: 사용자가 직접 기입하여 엔터를 누르면 캐시에 즉시 저장되고, 화면 갱신 시 자동 연산 값보다 사용자가 직접 타이핑한 값이 최우선적으로 로드 및 보존되도록 안정성을 재확인했습니다.
- **검증**: 파이썬 구문 문법 검사(`py_compile`) 완료.
