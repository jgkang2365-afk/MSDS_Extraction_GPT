# [사건 보고서] MSDS 함유량 부등호 유실 및 OCR 오인식 해결 (2026-05-03)

## 1. 개요
MSDS PDF 추출 시 `0.1~1미만`과 같은 범위형 함유량 데이터에서 부등호(`<`)가 유실되어 `0.1~1%`로 출력되는 문제가 발생함. 

## 2. 원인 분석
- **현상**: 엔진(v17.3.0.5)은 정교한 부등호 복구 로직을 갖추었으나, 특정 파일에서만 부등호가 유실됨.
- **범인 검거 (OCR Artifact)**: 지문 채취(Debug Print) 결과, PDF 텍스트 추출 엔진이 '만' 자를 **'맊' (U+B99A)**으로 잘못 읽어들이고 있었음.
- **결과**: 엔진은 '미만'이라는 단어만 찾고 있었기 때문에, '미맊'으로 추출된 데이터에서 부등호 키워드를 발견하지 못하고 숫지만 챙겨가는 현상이 발생함.

## 3. 해결책 (Surgical Patch)
- **정규식 강화**: `_normalize_single_content` 함수의 키워드 스캔 로직에 OCR 오인식 가능성이 있는 유사 글자를 포함시킴.
    - **미만 대응**: `미\s*[만맊먄]` (만, 맊, 먄 모두 허용)
    - **이하 대응**: `이\s*[하핚]` (하, 핚 모두 허용)
- **전처리 순서 변경**: 부등호 판별 전 공백을 먼저 제거하여 `미 만`과 같은 분절된 텍스트 대응력 강화.

## 4. 향후 대응 가이드
- **유사 문제 발생 시**: 
    1. 터미널 로그에서 `DEBUG_NORM` 또는 `raw_content`를 출력하여 PDF 라이브러리가 글자를 어떻게 읽어오는지 확인할 것.
    2. 눈에 보이는 글자와 실제 데이터(Unicode)가 다를 수 있음을 항상 전제할 것 (Glyph Confusion).
    3. 정규식에 유연한 허용 범위(Fuzzy Pattern)를 적용하여 대응할 것.
