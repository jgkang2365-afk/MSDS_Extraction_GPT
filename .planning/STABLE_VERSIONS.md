# Stable Milestones & Rollback Points

이 문서는 MSDS 추출 엔진의 주요 안정화 버전을 기록하며, 회귀(Regression) 발생 시 복구 지점으로 활용됩니다.

## 🏆 Current Gold Standard
- **Version**: `24.4.8.0`
- **Date**: 2026-06-13
- **Key Features**:
    - **하이브리드 JSON 정제 체인(Chaining) 완착**: 2단계 딥시크 OCR이 가져온 일반 마크다운 텍스트를 파싱 실패 시 버리지 않고, 가벼운 텍스트 전용 `gemini-2.5-flash-lite`를 거쳐 초저비용 구조화 JSON으로 변환해내는 2.5단계 융합 체인을 구축하여 딥시크의 밸류를 100% 실용화함.
    - **API 엔드포인트 누수 수정**: Novita AI의 최신 OpenAI 규격 베이스 URL(`https://api.novita.ai/v3/openai`)을 정밀 바인딩하고 HTTP 404 및 400 에러를 완전 퇴치.
