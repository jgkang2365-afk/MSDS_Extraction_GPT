# Stable Milestones & Rollback Points

이 문서는 MSDS 추출 엔진의 주요 안정화 버전을 기록하며, 회귀(Regression) 발생 시 복구 지점으로 활용됩니다.

## 🏆 Current Gold Standard
- **Version**: `24.4.4.0`
- **Date**: 2026-05-30
- **Key Features**:
    - **3중 스냅샷 타임라인 캐시 버전 레이어 설계**: 메모리 캐시 영역에 최초 순수 추출 원본(`v2.0_Clean`)과 수동 수정 확정본(`v3.0_Final`) 스냅샷 버전을 분리 적재하여, 수동 수정 전후의 데이터를 엄격하게 안전 격리 보존
    - **수동 개입 취소 및 기계 원본 복원 우클릭 메뉴 구현**: 테이블 컨텍스트 메뉴에 복원 기능을 탑재하여, 수동으로 수정한 행을 언제든 최초 분석 원본으로 신속하게 리셋하고 수동 락을 안전하게 해제하도록 복구 메커니즘을 연동
    - **수동 셀 직접 타이핑 시의 락킹 누수 방어**: 팝업창을 거치지 않고 셀을 직접 타이핑하여 수동 편집할 때도 수동 제어 락(`is_manual = True`)을 즉시 주입하고 `v3.0_Final`에 동기화해 기계적 오버라이트를 철저히 차단
    - **화학물질명 보존식 역방향 마스터 DB 중복 격멸 적용**: 쉼표(`,`)를 분쇄하는 기존 방식의 결함(1,2-디클로로에탄 등 고유명사 구조 파괴)을 박멸하고, 마스터 DB 내의 공인 측정대상 물질명을 기준으로 입력 문장을 역추적하는 [역방향 문자열 인클루드 검색 필터] `clean_measure_duplicates`를 설계하여 교정창 및 엑셀 저장부에 전면 이식
    - **성상 선택 팝업 물질명 오조회 버그(v3.7) 패치**: 성상 선택 다이얼로그 확인 시 마스터 DB 엔트리로부터 조회하는 물질명 키값을 존재하지 않는 키(`물질명`, `상용명`) 대신 공인 표준 키(`측정대상 물질명`)로 보정하여 물질명 누락(공백 처리) 오류 완치
