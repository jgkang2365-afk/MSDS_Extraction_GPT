# 📋 GUI 테이블 미리보기 초기화 문제 해결 계획

## 1. 개요
현재 GUI 테이블에서 같은 행의 다른 열을 클릭하거나 수정을 위해 더블 클릭할 때 미리보기(PDF)가 초기화되어 상단으로 이동하는 현상이 발생합니다. 이를 방지하기 위해 동일 행 내에서의 이동이나 중복 로드를 차단하는 로직을 구현합니다.

## 2. 세부 수정 사항

### 2.1. PDFPreviewPanel.load_pdf 수정 (`smu_gui.py`)
- **변경 사항**: 동일한 파일 경로가 이미 로드되어 있는 경우 로직을 건너뜁니다.
- **이유**: `load_pdf`는 호출될 때마다 레이아웃을 비우고 스크롤을 0으로 초기화하므로, 중복 호출을 막아야 합니다.

### 2.2. SMUGUI.sync_pdf_preview 수정 (`smu_gui.py`)
- **변경 사항**: 현재 선택된 행이 이전에 선택된 행과 동일한 경우 `load_pdf` 호출을 스킵합니다.
- **이유**: 사용자가 열을 이동(좌우 방향키나 클릭)할 때 `itemSelectionChanged`가 발생하는데, 행이 같다면 미리보기를 새로 고칠 필요가 없습니다.

### 2.3. SMUGUI.__init__ 수정 (`smu_gui.py`)
- **변경 사항**: `self.last_selected_row = -1` 변수를 초기화합니다.

## 3. 검증 계획
- 테이블의 특정 행을 클릭하여 PDF 로드 확인.
- 동일 행 내에서 다른 열을 클릭할 때 미리보기가 초기화(상단 이동)되지 않는지 확인.
- 셀을 더블 클릭하여 편집 모드로 진입할 때 미리보기가 유지되는지 확인.
- 다른 행으로 이동할 때는 정상적으로 해당 파일의 미리보기가 로드되는지 확인.
