# Implementation Plan - V17.4.0.3: Cross-Page Intelligence & Structural Extraction

## 1. 개요 (Overview)
- **현상**: MSDS 표가 페이지를 넘어가면서 '함유량' 헤더가 사라질 때, 엔진이 함량 열의 위치를 잃어버려 페이지 번호나 섹션 번호를 함량으로 오판하는 문제 발생.
- **원인**: 각 페이지를 독립적인 개체로 처리하여 좌표 문맥(Context)이 단절됨.
- **해결**: 첫 페이지의 좌표 정보를 다음 페이지로 계승(Inheritance)하고, 구조적 필터를 통해 노이즈를 차단함.

## 2. 상세 작업 (Details)

### A. msds_engine_v5.py 수술
1. **`extract_from_text_regex(page, log_func=None, inherited_x_range=None)`**
   - `inherited_x_range` 인자 추가.
   - 현재 페이지에서 헤더를 못 찾으면 `inherited_x_range`를 사용하여 `content_x_min/max` 설정.
   - **구조적 필터 적용**:
     - `best_match` 선정 시 `[CAS_ANCHOR]` 보다 왼쪽에 있는 텍스트는 `score_match`에서 대폭 감점 또는 제외.
     - 원본 텍스트에 `%`, `~`, `-`, `미만`, `이상` 중 하나라도 없으면 함량 후보에서 하순위로 밀어냄.
2. **`extract_components_odl_robust`**
   - 루프 시작 전 `current_content_x_range = None` 초기화.
   - 각 페이지 처리 후 `extract_from_text_regex`가 반환하는(또는 내부에서 갱신된) X 범위를 `current_content_x_range`에 업데이트.

### B. msds_utils_v3.py 보강
1. **`format_content` / `_normalize_single_content`**
   - '미만' 키워드 처리 강화: `0.1~1미만` -> `0.1~<1%` 형태로 변환하여 GUI의 1% 미만 로직이 작동하게 유도.

## 3. 검증 계획 (Verification)
1. **단위 테스트**: 4번 파일의 2페이지 텍스트 레이어를 모의(Mock)하여 `3`, `4`가 아닌 `0.1~1미만`을 가져오는지 확인.
2. **회귀 테스트**: 기존에 잘 되던 1페이지 성분(616-38-6 등)이 여전히 잘 나오는지 체크.
3. **통합 테스트**: GUI에서 4번 파일 재추출 시 로그 및 테이블 결과 확인.
