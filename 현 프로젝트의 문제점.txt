def find_section3_pages(doc):    pages = []    for i in range(len(doc)):        text = doc[i].get_text("text")        if re.search(r'3\.\s*구성|SECTION\s*3', text, re.I):            pages.append(i)        elif pages and re.search(r'4\.\s*응급|SECTION\s*4', text, re.I):            break    return pages

👉 중요:
❌ fallback으로 앞페이지 사용 금지
✔ 못 찾으면 → “추출 실패” 반환

✔ (B) 표 영역만 이미지로 자르기
def extract_table_images(doc, pages):    images = []    for p in pages:        page = doc[p]        pix = page.get_pixmap(matrix=fitz.Matrix(2.5, 2.5))        images.append(base64.b64encode(pix.tobytes("png")).decode())    return images[:2]

👉 핵심:
