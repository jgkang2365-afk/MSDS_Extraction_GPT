# 프로젝트: SAS 기반 차세대 MSDS 추출 엔진 고도화

## 1. 프로젝트 개요
- **상태**: 연구 및 설계 단계 (v2 → v3 전환)
- **핵심 목표**: 1차원 텍스트 스트림 탐색의 한계를 극복하고, PDF의 좌표(Coordinate) 정보를 활용한 **2D 공간 스코어링(Spatial Anchor Scoring, SAS)** 도입.

## 2. 현황 및 문제점
- **기술 부채**: `msds_engine_v2.py`의 윈도우 탐색 방식은 레이아웃이 복잡한 문서(예: 1013번)에서 탐색 범위를 늘릴 경우 다른 문서에서 회귀(Regression) 오류를 유발함.
- **유지보수 과부하**: 새로운 노이즈 단어가 발견될 때마다 `patterns.json`의 블랙리스트를 수동으로 업데이트하는 '두더지 잡기'식 대응의 한계 직면.

## 3. 로드맵
- **Phase 1**: `fitz` (PyMuPDF) `dict` 모드를 활용한 좌표 추출 엔진 교체.
- **Phase 2**: 앵커(키워드) 대비 후보군별 공간 정렬 점수(SAS) 알고리즘 구현.
- **Phase 3 (Optional)**: Ollama(로컬 LLM)를 활용한 최종 후보군 시맨틱 검증. SAS 정확도가 충분할 경우 생략 가능한 선택적 확장.
