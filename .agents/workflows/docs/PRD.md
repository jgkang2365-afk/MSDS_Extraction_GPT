# PRD: MSDS 공간 지능 추출 시스템 (v3)

## 1. 목적
MSDS PDF 문서 내에서 제품명, CAS 번호, 함유량을 로컬 환경에서 비용 발생 없이 무결점으로 추출한다. 특히 텍스트 순서가 꼬인 문서에서도 시각적 배치를 읽어내어 정확도를 극대화한다.

## 2. 사용자 가이드라인 및 제약사항
- **완전 로컬 구동**: 외부 API(OpenAI, Gemini 등) 호출 없이 내부 자원만 사용.
- **성능 무결성**: 기존 성공 케이스(8개 파일)의 결과값을 보존하면서 실패 케이스(1010, 7004, 1013)를 해결.
- **유연한 대응**: `patterns.json`에 의존하기보다 문서의 구조적 특징을 우선시함.

## 3. 핵심 기능 (Functional Requirements)
- **[FR-1] 공간 좌표 추출**: PDF 내 모든 단어의 x, y 좌표와 크기 정보를 획득.
- **[FR-2] 앵커 기반 스코어링**: '제품명' 키워드의 좌표를 기준으로 우측 및 하단 텍스트에 정렬 가산점 부여.
- **[FR-3] 로컬 검증기(Verifier) [Optional]**: 스코어 상위 후보군 중 진짜 제품명을 Ollama로 판별. Phase 1·2로 충분할 경우 생략 가능.
- **[FR-4] 레거시 통합**: 기존에 검증된 CAS 번호 정규화 및 유효성 검사 로직 유지.

## 4. 성공 지표 (Success Metrics)
- 하드코어 테스트 파일 11종 전체 통과율 100%.
- 제품명 추출 정확도(Precision) 98% 이상 달성.
