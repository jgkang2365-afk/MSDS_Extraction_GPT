# [GSD2] V17.3.1.16: CAS-함량 매핑 무결성 강화 계획

## 1. 개요 (Discuss)
013_아이생각수성내부프로 MSDS에서 발생하는 1페이지 성분(고분자 포함 8건) 추출 실패 문제를 해결합니다. 
**핵심 원칙**: PDF의 지저분한 성분명은 무시하고, 오직 **[CAS 번호]**와 **[함량(%)]**을 정확하게 매칭하여 추출하는 데 집중합니다.

## 2. 상세 설계 (Plan)

### [Forest] 사전 분석
- **현상**: 고분자처럼 정보가 여러 줄로 쪼개진 경우, 함량이 CAS 번호와 멀리 떨어져 있어 매핑에 실패함.
- **원인**: 현재 엔진이 너무 좁은 범위(단일 행 위주)에서만 함량을 찾으려 함.
- **DNA 대조**: 성분명은 코샤 API 및 마스터 데이터에서 보완하므로, 엔진은 CAS-함량 연결의 무결성만 책임짐.

### [Tree] 정밀 수정 단계 (Execute 예정)
